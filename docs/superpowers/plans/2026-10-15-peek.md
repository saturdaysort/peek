# Peek Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native macOS desktop pet that pops out of the bottom-right corner with a speech bubble when a Claude Desktop Code session finishes or needs you. Clicking it opens that exact session.

**Architecture:** A Claude Code hook (zsh) drops one small envelope file per event into a private inbox folder. `Peek.app` watches the folder and parses each event into a message. A pure `Director` state machine decides what the pet does; the AppKit layer only animates, draws, and performs the Director's effects (open the `claude://` deep link, chirp, restart the bubble timer). Everything with logic lives in `PeekCore` and is unit-tested. The AppKit target is verified live on screen.

**Tech Stack:** Swift 6.4 toolchain, Swift Package Manager (tools 6.0), AppKit, Core Graphics, ServiceManagement, Swift Testing (`import Testing`), zsh, Python 3 standard library (settings installer only). No third-party packages.

**Spec:** `docs/superpowers/specs/2026-10-15-peek-design.md`. Read it before starting any task.

## Global Constraints

- Platform: macOS 14 or later (`platforms: [.macOS(.v14)]`); built with `swift build`, no Xcode project file.
- Bundle id `dev.longbrook.peek`; installed at `~/Applications/Peek.app`; hook shipped at `Peek.app/Contents/Resources/peek-hook`.
- Inbox: `~/Library/Application Support/Peek/inbox`, mode 700. Files are named `<epoch-ms>-<pid>.event`. Line 1 is the Desktop session id; the rest is the hook's stdin JSON, capped at 1 MB. Files older than 1 hour are dropped unread.
- Deep link: `claude://code/continue?session=<id>`. The id must match `^local_[A-Za-z0-9-]{1,64}$`, or nothing is opened.
- Colors: clay `#D97757`, ink `#1F1A17`, paper `#FFFDF8`. Defined only in `Sprite.Palette`.
- Sprite: 16 x 9 cells at 5 pt (80 x 45 pt). Font: Press Start 2P at 8 pt with a 12 pt line height.
- Timings live only in `Timing`:
  - bubble stays 10 s, paused while hovered;
  - duck 0.42 s; walk in 1.1 s (done) or 0.7 s (needs you); walk out 0.9 s;
  - leg frame 0.13 s; blink every 2.6 s for 0.14 s; type-on 1.5 s.
- Queue: oldest first, one message per session, capacity 20.
- Copy, exact strings:
  - Bubble defaults: "Done", "Needs you", "Peek", "Nothing new".
  - Menu: "Dismiss", "Dismiss all", "Quiet for 1 hour", "End quiet hour", "Sound", "Open at login", "Quit Peek".
- No emoji anywhere: code, comments, copy, docs, commit messages.
- Git:
  - Run `git status --short` and stage explicit paths only. Never `git add -A` or `git add .`.
  - Never push, and never chain commit and push.
  - Never `reset --hard` or `clean -fd`.
- `~/.claude/settings.json` is changed only through `scripts/hooks.py`, and only after the user has seen and approved the diff in chat.

## Review Focus

1. A final message that opens with a code block, a table, or a horizontal rule. The bubble should show the first real sentence, never a fence, table, or code line. Tested in Task 1 (`skipsCodeFencesTablesAndRules`).
2. A final message larger than the hook's 1 MB cap. Claude must never wait or see a hook error, and you still get a "Done" bubble for the right session. Tested in Task 2 (`truncatedPayloadStillAnnounces`) and Task 3 (`hugePayloadIsCappedAndStillAnnounced`).
3. Two sessions finishing in the same instant. Both messages must arrive, and neither file may clobber the other. Tested in Task 3 (`writesOneEnvelopePerEvent`).
4. Clicking the pet while it is still walking in. It should open that session, not ignore the click. Tested in Task 6 (`clickWhileWalkingInOpensThatSession`).
5. Session titles and messages with accents or CJK characters. They must pass through trimming and queueing unchanged and render with a fallback font. Tested in Task 1 (`keepsUnicode`) and Task 6 (`unicodeSurvivesUnchanged`), then checked on screen in Task 12, Step 9.

import Foundation

/// Why the pet is showing up.
public enum MessageKind: String, Sendable, Equatable {
    /// A session finished its turn (Claude Code `Stop` hook).
    case done
    /// A session is waiting on a permission or a question (`Notification` hook).
    case needsYou

    /// Bubble text when the hook gave us nothing usable.
    public var fallbackText: String {
        switch self {
        case .done: "Done"
        case .needsYou: "Needs you"
        }
    }
}

/// One hook event, as read from the inbox.
public struct PeekEvent: Sendable, Equatable {
    public let hostSessionId: String
    public let kind: MessageKind
    public let text: String
    public let cwd: String?
    public let receivedAt: Date

    public init(hostSessionId: String, kind: MessageKind, text: String, cwd: String?, receivedAt: Date) {
        self.hostSessionId = hostSessionId
        self.kind = kind
        self.text = text
        self.cwd = cwd
        self.receivedAt = receivedAt
    }
}

/// What a bubble shows: an event plus the session's display title.
public struct Message: Sendable, Equatable {
    public let hostSessionId: String
    public let kind: MessageKind
    public let title: String
    public let text: String
    public let receivedAt: Date

    public init(hostSessionId: String, kind: MessageKind, title: String, text: String, receivedAt: Date) {
        self.hostSessionId = hostSessionId
        self.kind = kind
        self.title = title
        self.text = text
        self.receivedAt = receivedAt
    }

    public init(event: PeekEvent, title: String) {
        self.init(hostSessionId: event.hostSessionId, kind: event.kind, title: title,
                  text: event.text, receivedAt: event.receivedAt)
    }
}

`Sources/PeekCore/TextTrimmer.swift`:

```swift
import Foundation

/// Turns Claude's final Markdown message into one line of plain text for a speech bubble.
public enum TextTrimmer {
    /// The first line of prose, cleaned. Code fences (and everything inside them), table rows
    /// and horizontal rules are skipped. Nil when nothing usable is left.
    public static func summary(_ raw: String) -> String? {
        var inFence = false
        for line in raw.split(omittingEmptySubsequences: false, whereSeparator: \.isNewline) {
            let trimmed = line.trimmingCharacters(in: .whitespaces)
            if trimmed.hasPrefix("```") {
                inFence.toggle()
                continue
            }
            if inFence || trimmed.hasPrefix("|") || isRule(trimmed) { continue }
            let cleaned = clean(trimmed)
            if !cleaned.isEmpty { return cleaned }
        }
        return nil
    }

    /// `---`, `***`, `___`, `===`, with or without spaces between.
    static func isRule(_ line: String) -> Bool {
        let marks = line.filter { !$0.isWhitespace }
        guard marks.count >= 3, let first = marks.first, "-*_=".contains(first) else { return false }
        return marks.allSatisfy { $0 == first }
    }

    static func clean(_ line: String) -> String {
        var s = line
        s = s.replacingOccurrences(of: #"\[([^\]]*)\]\([^)]*\)"#, with: "$1", options: .regularExpression)
        s = s.replacingOccurrences(of: #"^(#{1,6}\s+|[-*+]\s+|\d+[.)]\s+|>\s*)"#, with: "", options: .regularExpression)
        s = s.replacingOccurrences(of: #"\*\*|__|\*|`"#, with: "", options: .regularExpression)
        s = s.replacingOccurrences(of: #"\s+"#, with: " ", options: .regularExpression)
        return s.trimmingCharacters(in: .whitespaces)
    }
}

```swift
import Foundation

/// The Claude Desktop URL that opens a Code session.
///
/// Found in Claude Desktop 2.37337.1's URL handler (app.asar); not documented by Anthropic.
/// `claude://code/continue?session=<id>` opens the non-archived session with that id and falls
/// back to the Code home screen otherwise. Claude checks the id against
/// ^local_[A-Za-z0-9-]{1,64}$ and so do we, so nothing read from the inbox can become an
/// arbitrary URL.
public enum DeepLink {
    public static func isValidSessionId(_ id: String) -> Bool {
        guard id.hasPrefix("local_") else { return false }
        let rest = id.dropFirst("local_".count)
        return (1...64).contains(rest.count)
            && rest.allSatisfy { $0.isASCII && ($0.isLetter || $0.isNumber || $0 == "-") }
    }

    public static func url(for hostSessionId: String) -> URL? {
        guard isValidSessionId(hostSessionId) else { return nil }
        return URL(string: "claude://code/continue?session=\(hostSessionId)")
    }
}

`Sources/PeekCore/EventParser.swift`:

```swift
import Foundation

/// Reads one inbox envelope: line 1 is the Desktop session id (CLAUDE_CODE_HOST_SESSION_ID),
/// the rest is the Claude Code hook's stdin JSON.
public enum EventParser {
    /// `idle_prompt` repeats a Stop we already showed; `auth_success` is not about a session.
    public static let ignoredNotificationTypes: Set<String> = ["idle_prompt", "auth_success"]

    public static func parse(_ data: Data, receivedAt: Date) -> PeekEvent? {
        guard let newline = data.firstIndex(of: 0x0A),
              let id = String(data: data[data.startIndex..<newline], encoding: .utf8),
              DeepLink.isValidSessionId(id) else { return nil }
        let body = Data(data[data.index(after: newline)...])
        guard let payload = (try? JSONDecoder().decode(HookPayload.self, from: body)) ?? HookPayload(salvaging: body)
        else { return nil }

        let kind: MessageKind
        let raw: String?
        switch payload.hook_event_name {
        case "Stop":
            kind = .done
            raw = payload.last_assistant_message
        case "Notification":
            if let type = payload.notification_type, ignoredNotificationTypes.contains(type) { return nil }
            kind = .needsYou
            raw = payload.message
        default:
            return nil
        }
        let text = raw.flatMap(TextTrimmer.summary) ?? kind.fallbackText
        return PeekEvent(hostSessionId: id, kind: kind, text: text, cwd: payload.cwd, receivedAt: receivedAt)
    }
}

/// The fields Peek uses from a Claude Code hook payload. Unknown fields are ignored.
struct HookPayload: Decodable {
    var hook_event_name: String
    var cwd: String?
    var last_assistant_message: String?
    var message: String?
    var notification_type: String?
}

extension HookPayload {
    /// For a payload the hook cut at its 1 MB cap: the event name and cwd come first in
    /// Claude Code's JSON, so recover them from the head and let the text fall back.
    init?(salvaging body: Data) {
        let head = String(decoding: body.prefix(4096), as: UTF8.self)
        guard let name = Self.field("hook_event_name", in: head) else { return nil }
        self.init(hook_event_name: name, cwd: Self.field("cwd", in: head), last_assistant_message: nil,
                  message: nil, notification_type: Self.field("notification_type", in: head))
    }

    static func field(_ key: String, in text: String) -> String? {
        let pattern = "\"\(key)\"\\s*:\\s*\"(?:[^\"\\\\]|\\\\.)*\""
        guard let range = text.range(of: pattern, options: .regularExpression) else { return nil }
        let match = text[range]
        guard let colon = match.firstIndex(of: ":") else { return nil }
        let literal = match[match.index(after: colon)...].trimmingCharacters(in: .whitespaces)
        return try? JSONDecoder().decode(String.self, from: Data(literal.utf8))
    }
}

```swift
import Foundation

/// The drop folder between the hook and the app. The hook writes `<epoch-ms>-<pid>.event`
/// files atomically (temp file, then rename); the app drains them in name order.
public struct Inbox: Sendable {
    /// Relative to the home folder. hook/peek-hook hard-codes the same path; a test keeps them in step.
    public static let relativePath = "Library/Application Support/Peek/inbox"
    /// Older events are dropped unread, so a long absence doesn't produce a flood.
    public static let staleAfter: TimeInterval = 3600
    /// The hook's 1 MB cap plus the id line, with room to spare. Bigger files didn't come from the hook.
    public static let maxFileSize = 2 * 1024 * 1024

    public let directory: URL

    public init(directory: URL) {
        self.directory = directory
    }

    public static var standard: Inbox {
        Inbox(directory: FileManager.default.homeDirectoryForCurrentUser.appendingPathComponent(relativePath))
    }

    /// Parses and deletes every `.event` file, oldest name first. Stale, oversized and malformed
    /// files are deleted without producing an event. Dot-prefixed temp files are left alone.
    public func drain(now: Date = Date()) -> [PeekEvent] {
        let fm = FileManager.default
        let keys: [URLResourceKey] = [.contentModificationDateKey, .fileSizeKey]
        guard let files = try? fm.contentsOfDirectory(at: directory, includingPropertiesForKeys: keys) else { return [] }
        var events: [PeekEvent] = []
        let ready = files.filter { $0.pathExtension == "event" }.sorted { $0.lastPathComponent < $1.lastPathComponent }
        for file in ready {
            defer { try? fm.removeItem(at: file) }
            let values = try? file.resourceValues(forKeys: Set(keys))
            let modified = values?.contentModificationDate ?? now
            guard now.timeIntervalSince(modified) < Self.staleAfter,
                  (values?.fileSize ?? 0) <= Self.maxFileSize,
                  let data = try? Data(contentsOf: file),
                  let event = EventParser.parse(data, receivedAt: modified) else { continue }
            events.append(event)
        }
        return events
    }
}

import Foundation

/// What Peek reads from a Claude Desktop session file.
public struct SessionInfo: Sendable, Equatable {
    public let title: String?
    public let isArchived: Bool
    /// Milliseconds since 1970; updated when you switch to the session in Claude.
    public let lastFocusedAt: Double?

    public init(title: String?, isArchived: Bool, lastFocusedAt: Double?) {
        self.title = title
        self.isArchived = isArchived
        self.lastFocusedAt = lastFocusedAt
    }
}

/// Claude Desktop keeps one JSON file per Code session at
/// `<root>/<account-uuid>/<org-uuid>/local_<uuid>.json`. The layout is undocumented (observed in
/// Claude 2.37337.1), so every read here degrades to nil instead of failing.
public struct SessionDirectory: Sendable {
    public let root: URL

    public init(root: URL) {
        self.root = root
    }

    public static var claudeDefault: SessionDirectory {
        SessionDirectory(root: FileManager.default.homeDirectoryForCurrentUser
            .appendingPathComponent("Library/Application Support/Claude/claude-code-sessions"))
    }

    public func info(for id: String) -> SessionInfo? {
        guard DeepLink.isValidSessionId(id) else { return nil }
        for dir in orgDirectories() {
            if let info = Self.read(dir.appendingPathComponent("\(id).json")) { return info }
        }
        return nil
    }

    /// The session you most recently switched to. Only the `candidates` most recently modified
    /// files are read: there are hundreds of them (24 MB on the dev Mac), and switching to a
    /// session rewrites its file, so the answer is always among the newest.
    public func mostRecentlyFocusedId(candidates: Int = 5) -> String? {
        let fm = FileManager.default
        var files: [(url: URL, modified: Date)] = []
        for dir in orgDirectories() {
            let urls = (try? fm.contentsOfDirectory(at: dir, includingPropertiesForKeys: [.contentModificationDateKey])) ?? []
            for url in urls where url.pathExtension == "json"
                && DeepLink.isValidSessionId(url.deletingPathExtension().lastPathComponent) {
                let modified = (try? url.resourceValues(forKeys: [.contentModificationDateKey]).contentModificationDate) ?? .distantPast
                files.append((url, modified))
            }
        }
        var best: (id: String, at: Double)?
        for file in files.sorted(by: { $0.modified > $1.modified }).prefix(candidates) {
            guard let at = Self.read(file.url)?.lastFocusedAt else { continue }
            if best.map({ at > $0.at }) ?? true {
                best = (file.url.deletingPathExtension().lastPathComponent, at)
            }
        }
        return best?.id
    }

    /// The session's title, else its project folder's name, else "Claude".
    public static func displayTitle(info: SessionInfo?, cwd: String?) -> String {
        if let title = info?.title?.trimmingCharacters(in: .whitespacesAndNewlines), !title.isEmpty { return title }
        if let cwd, !cwd.isEmpty {
            let name = URL(fileURLWithPath: cwd).lastPathComponent
            if !name.isEmpty, name != "/" { return name }
        }
        return "Claude"
    }

    private func orgDirectories() -> [URL] {
        let fm = FileManager.default
        let accounts = (try? fm.contentsOfDirectory(at: root, includingPropertiesForKeys: nil)) ?? []
        return accounts.flatMap { (try? fm.contentsOfDirectory(at: $0, includingPropertiesForKeys: nil)) ?? [] }
    }

    private static func read(_ file: URL) -> SessionInfo? {
        guard let data = try? Data(contentsOf: file),
              let raw = try? JSONDecoder().decode(RawSession.self, from: data) else { return nil }
        return SessionInfo(title: raw.title, isArchived: raw.isArchived ?? false, lastFocusedAt: raw.lastFocusedAt)
    }

    private struct RawSession: Decodable {
        let title: String?
        let isArchived: Bool?
        let lastFocusedAt: Double?
    }
}

import Foundation

/// Unread messages, oldest first, at most one per session.
public struct MessageQueue: Sendable, Equatable {
    public static let capacity = 20

    public private(set) var items: [Message] = []
    /// Which message the bubble is showing.
    public private(set) var currentIndex = 0

    public init() {}

    public var isEmpty: Bool { items.isEmpty }
    public var count: Int { items.count }
    public var current: Message? { items.indices.contains(currentIndex) ? items[currentIndex] : nil }

    /// Adds a message, or replaces the same session's older one in place. Returns its index.
    @discardableResult
    public mutating func upsert(_ message: Message) -> Int {
        if let i = items.firstIndex(where: { $0.hostSessionId == message.hostSessionId }) {
            items[i] = message
            return i
        }
        items.append(message)
        if items.count > Self.capacity {
            items.removeFirst()
            currentIndex = max(0, currentIndex - 1)
        }
        return items.count - 1
    }

    public mutating func remove(sessionId: String) {
        guard let i = items.firstIndex(where: { $0.hostSessionId == sessionId }) else { return }
        items.remove(at: i)
        if i < currentIndex { currentIndex -= 1 }
        clamp()
    }

    public mutating func removeAll() {
        items.removeAll()
        currentIndex = 0
    }

    public mutating func show(index: Int) {
        currentIndex = index
        clamp()
    }

    public mutating func showOldest() {
        currentIndex = 0
    }

    /// Moves through the queue, stopping at either end.
    public mutating func step(_ delta: Int) {
        currentIndex += delta
        clamp()
    }

    private mutating func clamp() {
        currentIndex = items.isEmpty ? 0 : min(max(currentIndex, 0), items.count - 1)
    }
}

```swift
import Foundation

/// The pet's behavior, with no AppKit and no clock. The app feeds it inputs (a message arrived,
/// an animation finished, the bubble timed out, a click) and performs the effects it returns.
public struct Director: Sendable {
    public enum Phase: Sendable, Equatable {
        case hidden, entering, showing, peeking, leaving
    }

    public enum Animation: Sendable, Equatable {
        /// Scuttle in from the right edge, then one hop (done) or two bounces (needs you).
        case enter(MessageKind)
        /// Scuttle in already ducked: a quiet hour ended with unread messages.
        case enterPeeking
        case hop
        case duck
        case unduck
        case leave
    }

    public enum Effect: Sendable, Equatable {
        case animate(Animation)
        case open(URL)
        case chirp
        case restartBubbleTimer
    }

    public static let greetingTitle = "Peek"
    public static let greetingText = "Nothing new"

    public private(set) var phase: Phase = .hidden
    public private(set) var queue = MessageQueue()
    /// True while the bubble is saying "Nothing new" after you opened Peek by hand.
    public private(set) var isGreeting = false
    public private(set) var quietUntil: Date?

    public init(quietUntil: Date? = nil) {
        self.quietUntil = quietUntil
    }

    public func isQuiet(at now: Date) -> Bool {
        quietUntil.map { now < $0 } ?? false
    }

    /// What the bubble says, when it is out.
    public var bubbleMessage: Message? {
        guard phase == .showing else { return nil }
        if isGreeting {
            return Message(hostSessionId: "", kind: .done, title: Self.greetingTitle,
                           text: Self.greetingText, receivedAt: .distantPast)
        }
        return queue.current
    }

    /// With the bubble out: the others waiting. While peeking: everything unread.
    public var badgeCount: Int {
        switch phase {
        case .peeking: queue.count
        case .entering, .showing: isGreeting ? 0 : max(0, queue.count - 1)
        case .hidden, .leaving: 0
        }
    }

    // MARK: Inputs

    public mutating func receive(_ message: Message, now: Date) -> [Effect] {
        let index = queue.upsert(message)
        if isQuiet(at: now) { return [] }
        switch phase {
        case .hidden, .leaving:
            isGreeting = false
            queue.show(index: index)
            phase = .entering
            return [.chirp, .animate(.enter(message.kind))]
        case .peeking:
            queue.show(index: index)
            phase = .showing
            return [.chirp, .animate(.unduck), .restartBubbleTimer]
        case .entering:
            if isGreeting {
                isGreeting = false
                queue.show(index: index)
            }
            return [.chirp]
        case .showing:
            guard isGreeting else { return [.chirp] }   // never interrupt a message being read
            isGreeting = false
            queue.show(index: index)
            return [.chirp, .animate(.hop), .restartBubbleTimer]
        }
    }

    public mutating func entranceFinished() -> [Effect] {
        guard phase == .entering else { return [] }
        phase = .showing
        return [.restartBubbleTimer]
    }

    public mutating func bubbleTimedOut() -> [Effect] {
        guard phase == .showing else { return [] }
        if isGreeting || queue.isEmpty { return leave() }
        phase = .peeking
        return [.animate(.duck)]
    }

    public mutating func clicked() -> [Effect] {
        switch phase {
        case .peeking:
            queue.showOldest()
            phase = .showing
            return [.animate(.unduck), .restartBubbleTimer]
        case .entering, .showing:
            if isGreeting { return leave() }
            guard let current = queue.current else { return leave() }
            queue.remove(sessionId: current.hostSessionId)
            let open: [Effect] = DeepLink.url(for: current.hostSessionId).map { [.open($0)] } ?? []
            return open + afterRemoval()
        case .hidden, .leaving:
            return []
        }
    }

    public mutating func scroll(by delta: Int) -> [Effect] {
        guard phase == .showing, !isGreeting else { return [] }
        let before = queue.currentIndex
        queue.step(delta)
        return queue.currentIndex == before ? [] : [.restartBubbleTimer]
    }

    public mutating func dismissCurrent() -> [Effect] {
        switch phase {
        case .entering, .showing:
            if isGreeting { return leave() }
            if let current = queue.current { queue.remove(sessionId: current.hostSessionId) }
            return afterRemoval()
        case .peeking:
            if let current = queue.current { queue.remove(sessionId: current.hostSessionId) }
            queue.showOldest()
            return queue.isEmpty ? leave() : []
        case .hidden, .leaving:
            return []
        }
    }

    public mutating func dismissAll() -> [Effect] {
        queue.removeAll()
        isGreeting = false
        return phase == .hidden || phase == .leaving ? [] : leave()
    }

    public mutating func leaveFinished() -> [Effect] {
        guard phase == .leaving else { return [] }
        phase = .hidden
        isGreeting = false
        return []
    }

    /// You opened Peek by hand: come out with the queue, or say there's nothing new.
    public mutating func greet() -> [Effect] {
        switch phase {
        case .hidden, .leaving:
            isGreeting = queue.isEmpty
            queue.showOldest()
            phase = .entering
            return [.animate(.enter(.done))]
        case .peeking:
            return clicked()
        case .entering, .showing:
            return []
        }
    }

    public mutating func startQuiet(until: Date) -> [Effect] {
        quietUntil = until
        isGreeting = false
        return phase == .hidden || phase == .leaving ? [] : leave()
    }

    public mutating func quietEnded() -> [Effect] {
        quietUntil = nil
        guard phase == .hidden, !queue.isEmpty else { return [] }
        queue.showOldest()
        phase = .peeking
        return [.animate(.enterPeeking)]
    }

    // MARK: Helpers

    private mutating func afterRemoval() -> [Effect] {
        queue.showOldest()
        guard !queue.isEmpty else { return leave() }
        phase = .showing
        return [.animate(.hop), .restartBubbleTimer]
    }

    private mutating func leave() -> [Effect] {
        phase = .leaving
        return [.animate(.leave)]
    }
}

import Foundation

/// The Block buddy and the bubble tail as pixel maps. This file is the single source of truth
/// for the character's shape and colors; the app only scales and paints it.
/// Map characters: `o` clay, `k` ink, `p` paper, `.` clear.
public enum Sprite {
    /// Points per sprite pixel: 10 device pixels on Retina, so edges stay crisp.
    public static let pixel = 5.0
    public static let columns = 16

    public static let body: [String] = [
        "..oooooooooooo..",
        "..ookkooookkoo..",
        "..ookkooookkoo..",
        "oooooooooooooooo",
        "oooooooooooooooo",
        "..oooooooooooo..",
        "..oooooooooooo..",
    ]
    /// Standing pose, and one of the two walking frames.
    public static let legsA: [String] = [
        "..o.o......o.o..",
        "..o.o......o.o..",
    ]
    public static let legsB: [String] = [
        "...o.o....o.o...",
        "...o.o....o.o...",
    ]

    public static let rowCount = body.count + legsA.count
    public static let width = Double(columns) * pixel
    public static let height = Double(rowCount) * pixel

    /// Drawn at `tailPixel` points per cell. The top row overlaps the bubble's 3 pt bottom border,
    /// so its paper cells open the border into the tail.
    public static let tailPixel = 3.0
    public static let tail: [String] = [
        "kppppk",
        ".kpppk",
        "..kppk",
        "...kpk",
        "....kk",
    ]

    public enum Palette {
        public static let clay: UInt32 = 0xD97757
        public static let ink: UInt32 = 0x1F1A17
        public static let paper: UInt32 = 0xFFFDF8
    }

    /// Rows from top to bottom. `stride` shows the mid-step legs; `blinking` closes the eyes.
    public static func rows(stride: Bool, blinking: Bool) -> [String] {
        let rows = body + (stride ? legsB : legsA)
        return blinking ? rows.map { $0.replacingOccurrences(of: "k", with: "o") } : rows
    }

    public static func color(_ c: Character) -> UInt32? {
        switch c {
        case "o": Palette.clay
        case "k": Palette.ink
        case "p": Palette.paper
        default: nil
        }
    }
}

import Foundation

/// Where the pet is, relative to its home spot in the corner.
public struct Pose: Sendable, Equatable {
    /// Points toward the right screen edge. 0 is home; `Geometry.offstage` is fully past the edge.
    public var x: Double
    /// Points upward. Negative values sink the pet below the bottom edge (ducking).
    public var y: Double
    /// True while the legs should alternate.
    public var walking: Bool

    public init(x: Double, y: Double, walking: Bool = false) {
        self.x = x
        self.y = y
        self.walking = walking
    }

    public static let home = Pose(x: 0, y: 0)
    public static let offstage = Pose(x: Geometry.offstage, y: 0)
}

/// Every duration, in seconds, in one place.
public enum Timing {
    public static let walkInDone = 1.1
    public static let walkInNeedsYou = 0.7
    public static let walkOut = 0.9
    /// One hop is two halves: up, then down.
    public static let hopHalf = 0.11
    public static let duck = 0.42
    public static let unduck = 0.16
    public static let legFrame = 0.13
    public static let blinkEvery = 2.6
    public static let blinkFor = 0.14
    public static let bubblePop = 0.18
    public static let typeOn = 1.5
    public static let bubbleStays = 10.0
    public static let bangBlink = 0.5
}

/// Distances, in points.
public enum Geometry {
    public static let rightInset = 12.0
    /// Far enough right that the pet is entirely past the screen edge.
    public static let offstage = rightInset + Sprite.width + 8
    public static let hopHeight = 10.0
    /// While peeking, the top three sprite rows (the eyes) stay above the edge.
    public static let peekShowing = 3 * Sprite.pixel
    public static let duckDepth = Sprite.height - peekShowing
}

/// One animation as a pure function of elapsed time. Walking moves in whole sprite pixels and
/// vertical moves are stepped, so the motion reads as pixel art rather than smooth easing.
public struct Motion: Sendable {
    public let animation: Director.Animation
    public let from: Pose

    public init(_ animation: Director.Animation, from: Pose) {
        self.animation = animation
        self.from = from
    }

    public var duration: Double {
        switch animation {
        case .duck: Timing.duck
        case .unduck: Timing.unduck
        default: walkDuration + Double(hops) * 2 * Timing.hopHalf
        }
    }

    public func isFinished(at elapsed: Double) -> Bool { elapsed >= duration }

    public func pose(at elapsed: Double) -> Pose {
        let t = min(max(elapsed, 0), duration)
        switch animation {
        case .duck:
            return Pose(x: from.x, y: stepped(from: from.y, to: -Geometry.duckDepth, progress: t / Timing.duck, steps: 6))
        case .unduck:
            return Pose(x: from.x, y: stepped(from: from.y, to: 0, progress: t / Timing.unduck, steps: 3))
        default:
            break
        }
        if let target = walkTarget, t < walkDuration {
            let x = from.x + (target - from.x) * (t / walkDuration)
            return Pose(x: snapped(x), y: groundY, walking: true)
        }
        let hopTime = t - walkDuration
        let inHops = hopTime < Double(hops) * 2 * Timing.hopHalf
        let up = inHops && Int(hopTime / Timing.hopHalf) % 2 == 0
        return Pose(x: walkTarget ?? from.x, y: groundY + (up ? Geometry.hopHeight : 0))
    }

    private var walkTarget: Double? {
        switch animation {
        case .enter, .enterPeeking: 0
        case .leave: Geometry.offstage
        case .hop, .duck, .unduck: nil
        }
    }

    /// Walks cover distance at a fixed speed, so turning back halfway doesn't sprint.
    private var walkDuration: Double {
        guard let target = walkTarget else { return 0 }
        let fullWalk: Double
        switch animation {
        case .enter(.needsYou): fullWalk = Timing.walkInNeedsYou
        case .leave: fullWalk = Timing.walkOut
        default: fullWalk = Timing.walkInDone
        }
        return fullWalk * abs(target - from.x) / Geometry.offstage
    }

    private var hops: Int {
        switch animation {
        case .enter(.done), .hop: 1
        case .enter(.needsYou): 2
        case .enterPeeking, .duck, .unduck, .leave: 0
        }
    }

    /// The height the pet walks and lands at.
    private var groundY: Double {
        switch animation {
        case .enterPeeking: -Geometry.duckDepth
        case .leave: from.y
        default: 0
        }
    }

    private func snapped(_ x: Double) -> Double { (x / Sprite.pixel).rounded() * Sprite.pixel }

    private func stepped(from a: Double, to b: Double, progress: Double, steps: Int) -> Double {
        let q = (min(max(progress, 0), 1) * Double(steps)).rounded(.up) / Double(steps)
        return a + (b - a) * q
    }
}

/// Drawn only at 8 pt: the face is built on an 8 px grid, so 8 pt lands on exactly
/// 2 device pixels per font pixel on Retina. Any other size blurs.

    static let lineHeight: CGFloat = 12

            NSLog("Peek: font registration failed: %@", String(describing: error?.takeRetainedValue()))
        }
    }

    static var font: NSFont {
        NSFont(name: postScriptName, size: size) ?? .monospacedSystemFont(ofSize: 10, weight: .regular)

import AppKit
import PeekCore

/// Size and placement of the speech bubble for one message, measured once per message.
struct BubbleLayout {
    static let maxWidth: CGFloat = 248
    static let minWidth: CGFloat = 120
    static let border: CGFloat = 3
    static let padding: CGFloat = 8
    static let titleGap: CGFloat = 4
    static let bodyLines = 3
    /// The bubble overlaps the pet's left edge by this much, so the tail lands on its head.
    static let overlap: CGFloat = 14
    /// Space between the pet's head and the bubble's bottom edge, where the tail hangs.
    static let lift: CGFloat = 17

    let message: Message
    let frame: NSRect
    let titleRect: NSRect
    let bodyRect: NSRect
    let tailOrigin: NSPoint

    init(message: Message, petHome: NSRect) {
        self.message = message
        let chrome = 2 * (Self.border + Self.padding)
        let maxText = Self.maxWidth - chrome
        let titleWidth = Self.title(for: message, bangOn: true).size().width
        let body = Self.text(message.text, color: Palette.ink, lineBreak: .byWordWrapping)
        let textWidth = min(maxText, ceil(max(titleWidth, body.size().width)))
        let bodyHeight = body.boundingRect(with: NSSize(width: textWidth, height: .greatestFiniteMagnitude),
                                           options: .usesLineFragmentOrigin).height
        let lines = max(1, min(Self.bodyLines, Int((bodyHeight / PixelFont.lineHeight).rounded(.up))))

        let width = max(Self.minWidth, textWidth + chrome).rounded(.up)
        let height = (CGFloat(1 + lines) * PixelFont.lineHeight + Self.titleGap + chrome).rounded(.up)
        frame = NSRect(x: (petHome.minX + Self.overlap - width).rounded(), y: petHome.maxY + Self.lift,
                       width: width, height: height)

        let inner = frame.insetBy(dx: Self.border + Self.padding, dy: Self.border + Self.padding)
        titleRect = NSRect(x: inner.minX, y: inner.maxY - PixelFont.lineHeight,
                           width: inner.width, height: PixelFont.lineHeight)
        bodyRect = NSRect(x: inner.minX, y: inner.minY,
                          width: inner.width, height: CGFloat(lines) * PixelFont.lineHeight)
        // The tail's top row sits on the bottom border, near the right edge, pointing at the pet.
        tailOrigin = NSPoint(x: frame.maxX - 30,
                             y: frame.minY - CGFloat(Sprite.tail.count - 1) * Sprite.tailPixel)
    }

    func titleString(bangOn: Bool) -> NSAttributedString {
        Self.title(for: message, bangOn: bangOn)
    }

    /// The whole message laid out, with the first `revealed` characters inked and the rest
    /// clear, so typing on never reflows the lines.
    func bodyString(revealed: Int) -> NSAttributedString {
        let text = message.text
        let s = NSMutableAttributedString(attributedString: Self.text(text, color: .clear, lineBreak: .byWordWrapping))
        let end = text.index(text.startIndex, offsetBy: min(max(revealed, 0), text.count))
        s.addAttribute(.foregroundColor, value: Palette.ink, range: NSRange(text.startIndex..<end, in: text))
        return s
    }

    private static func title(for message: Message, bangOn: Bool) -> NSAttributedString {
        let s = NSMutableAttributedString()
        if message.kind == .needsYou {
            s.append(text("! ", color: bangOn ? Palette.ink : .clear, lineBreak: .byTruncatingTail))
        }
        s.append(text(message.title, color: Palette.ink.withAlphaComponent(0.6), lineBreak: .byTruncatingTail))
        return s
    }

    private static func text(_ string: String, color: NSColor, lineBreak: NSLineBreakMode) -> NSAttributedString {
        let paragraph = NSMutableParagraphStyle()
        paragraph.minimumLineHeight = PixelFont.lineHeight
        paragraph.maximumLineHeight = PixelFont.lineHeight
        paragraph.lineBreakMode = lineBreak
        return NSAttributedString(string: string, attributes: [
            .font: PixelFont.font, .foregroundColor: color, .paragraphStyle: paragraph,
        ])
    }
}

`Sources/Peek/PetView.swift`:

```swift
import AppKit
import PeekCore

/// Draws the pet, its bubble and the badge from a `State` snapshot, and reports clicks, scrolls
/// and right-clicks on them. It has no behavior of its own; PetController decides everything.
final class PetView: NSView {
    struct State: Equatable {
        var pose = Pose.offstage
        var stride = false
        var blinking = false
        var bubble: Message?
        var revealed = 0
        var popScale = 0.0
        var bangOn = true
        var badge = 0
    }

    var state = State() {
        didSet { if state != oldValue { needsDisplay = true } }
    }
    var onClick: (() -> Void)?
    var onScroll: ((Int) -> Void)?
    var menuProvider: (() -> NSMenu?)?

    private var scrollAccumulator: CGFloat = 0
    private var cachedLayout: BubbleLayout?

    override var isFlipped: Bool { false }
    override func acceptsFirstMouse(for event: NSEvent?) -> Bool { true }

    // MARK: Geometry

    /// Feet on the bottom edge, 12 pt in from the right edge.
    private var homeRect: NSRect {
        NSRect(x: bounds.maxX - Geometry.rightInset - Sprite.width, y: 0, width: Sprite.width, height: Sprite.height)
    }

    private var petRect: NSRect { homeRect.offsetBy(dx: state.pose.x, dy: state.pose.y) }

    private var layout: BubbleLayout? {
        guard let message = state.bubble else { return nil }
        if cachedLayout?.message != message { cachedLayout = BubbleLayout(message: message, petHome: homeRect) }
        return cachedLayout
    }

    private var badgeText: NSAttributedString? {
        guard state.badge > 0 else { return nil }
        return NSAttributedString(string: "\(state.badge)", attributes: [.font: PixelFont.font, .foregroundColor: Palette.paper])
    }

    /// On the pet's top-right corner, so it stays visible while peeking.
    private var badgeRect: NSRect? {
        guard let text = badgeText else { return nil }
        let width = ceil(text.size().width) + 6
        return NSRect(x: petRect.maxX - width + 3, y: petRect.maxY - 3, width: width, height: PixelFont.lineHeight)
    }

    /// True when the pointer is over something visible: the pet, the badge, or a fully popped bubble.
    var containsMouse: Bool {
        guard let window else { return false }
        let point = convert(window.convertPoint(fromScreen: NSEvent.mouseLocation), from: nil)
        var targets = [petRect.intersection(bounds)]
        if let badge = badgeRect { targets.append(badge) }
        if let layout, state.popScale >= 1 { targets.append(layout.frame) }
        return targets.contains { !$0.isEmpty && $0.contains(point) }
    }

    // MARK: Input

    override func mouseDown(with event: NSEvent) {
        if containsMouse { onClick?() }
    }

    override func scrollWheel(with event: NSEvent) {
        // Trackpads send many small precise deltas; mouse wheels send whole lines.
        scrollAccumulator += event.hasPreciseScrollingDeltas ? event.scrollingDeltaY : event.scrollingDeltaY * 20
        while abs(scrollAccumulator) >= 20 {
            onScroll?(scrollAccumulator > 0 ? -1 : 1)
            scrollAccumulator -= scrollAccumulator > 0 ? 20 : -20
        }
    }

    override func menu(for event: NSEvent) -> NSMenu? { menuProvider?() }

    // MARK: Drawing

    override func draw(_ dirtyRect: NSRect) {
        guard let ctx = NSGraphicsContext.current?.cgContext else { return }
        paint(Sprite.rows(stride: state.stride, blinking: state.blinking), at: petRect.origin, cell: Sprite.pixel, in: ctx)
        if let layout, let message = state.bubble, state.popScale > 0 {
            ctx.saveGState()
            // Pop out of the tail corner.
            ctx.translateBy(x: layout.frame.maxX, y: layout.frame.minY)
            ctx.scaleBy(x: state.popScale, y: state.popScale)
            ctx.translateBy(x: -layout.frame.maxX, y: -layout.frame.minY)
            drawBubble(layout, message: message, in: ctx)
            ctx.restoreGState()
        }
        drawBadge(in: ctx)
    }

    /// Paints a pixel map (rows top to bottom) with its bottom-left cell at `origin`.
    private func paint(_ rows: [String], at origin: NSPoint, cell: CGFloat, in ctx: CGContext) {
        for (r, row) in rows.enumerated() {
            let y = origin.y + CGFloat(rows.count - 1 - r) * cell
            for (c, ch) in row.enumerated() {
                guard let hex = Sprite.color(ch) else { continue }
                ctx.setFillColor(NSColor(hex: hex).cgColor)
                ctx.fill(CGRect(x: origin.x + CGFloat(c) * cell, y: y, width: cell, height: cell))
            }
        }
    }

    private func drawBubble(_ layout: BubbleLayout, message: Message, in ctx: CGContext) {
        let frame = layout.frame
        let b = BubbleLayout.border
        // Ink with notched corners: two overlapping bars leave each b x b corner clear.
        ctx.setFillColor(Palette.ink.cgColor)
        ctx.fill(frame.insetBy(dx: b, dy: 0))
        ctx.fill(frame.insetBy(dx: 0, dy: b))
        ctx.setFillColor(Palette.paper.cgColor)
        ctx.fill(frame.insetBy(dx: b, dy: b))
        paint(Sprite.tail, at: layout.tailOrigin, cell: Sprite.tailPixel, in: ctx)
        let options: NSString.DrawingOptions = [.usesLineFragmentOrigin, .truncatesLastVisibleLine]

import AppKit

/// A 120 ms two-note square-wave blip (B5 then E6), synthesized once as an 8-bit WAV.
enum Chirp {
    private static let sound = NSSound(data: wav())

    static func play() {
        sound?.stop()
        sound?.play()
    }

    private static func wav() -> Data {
        let rate = 22_050
        var samples: [UInt8] = []
        for (frequency, milliseconds) in [(987.77, 55), (1318.51, 65)] {
            let count = rate * milliseconds / 1000
            for i in 0..<count {
                let high = (Double(i) * frequency / Double(rate)).truncatingRemainder(dividingBy: 1) < 0.5
                let fade = 1 - Double(i) / Double(count) * 0.5
                samples.append(UInt8(128.0 + (high ? 1.0 : -1.0) * 28.0 * fade))
            }
        }
        var data = Data()
        func u32(_ v: Int) { withUnsafeBytes(of: UInt32(v).littleEndian) { data.append(contentsOf: $0) } }
        func u16(_ v: Int) { withUnsafeBytes(of: UInt16(v).littleEndian) { data.append(contentsOf: $0) } }
        data.append(contentsOf: Array("RIFF".utf8)); u32(36 + samples.count)
        data.append(contentsOf: Array("WAVEfmt ".utf8)); u32(16); u16(1); u16(1); u32(rate); u32(rate); u16(1); u16(8)
        data.append(contentsOf: Array("data".utf8)); u32(samples.count)
        data.append(contentsOf: samples)
        return data
    }
}

```swift
import Foundation
import PeekCore

/// Watches the inbox folder and hands each batch of new events to `onEvents` on the main queue.
/// The hook's rename into the folder is a directory write, which is what wakes us.
final class InboxWatcher {
    private let inbox: Inbox
    private let onEvents: ([PeekEvent]) -> Void
    private var source: DispatchSourceFileSystemObject?

    init(inbox: Inbox, onEvents: @escaping ([PeekEvent]) -> Void) {
        self.inbox = inbox
        self.onEvents = onEvents
    }

    func start() {
        try? FileManager.default.createDirectory(at: inbox.directory, withIntermediateDirectories: true,
                                                 attributes: [.posixPermissions: 0o700])
        drain()   // events that arrived while Peek wasn't running (stale ones are dropped)
        let fd = open(inbox.directory.path, O_EVTONLY)
        guard fd >= 0 else {
            NSLog("Peek: cannot watch %@", inbox.directory.path)
            return
        }
        let source = DispatchSource.makeFileSystemObjectSource(fileDescriptor: fd, eventMask: .write, queue: .main)
        source.setEventHandler { [weak self] in self?.drain() }
        source.setCancelHandler { close(fd) }
        source.resume()
        self.source = source
    }

    private func drain() {
        let events = inbox.drain()
        guard !events.isEmpty else { return }
        NSLog("Peek: received %ld event(s)", events.count)
        onEvents(events)
    }
}

import AppKit
import PeekCore

/// Connects the pure Director to the screen. It owns the panel and a 60 Hz clock that runs only
/// while the pet is visible, performs the Director's effects, and feeds it the time-based inputs
/// (an animation finished, the bubble timed out).
final class PetController {
    static let claudeBundleId = "com.anthropic.claudefordesktop"

    private(set) var director: Director
    let panel = PetPanel()
    let view = PetView(frame: NSRect(origin: .zero, size: PetPanel.size))
    var quietTimer: Timer?

    private let sessions = SessionDirectory.claudeDefault
    private var clock: Timer?
    private var lastTick = 0.0
    private var motion: Motion?
    private var motionStart = 0.0
    private var pose = Pose.offstage
    private var bubbleRemaining = Timing.bubbleStays
    private var shownMessage: Message?
    private var shownAt = 0.0

    init(quietUntil: Date? = nil) {
        director = Director(quietUntil: quietUntil)
        panel.contentView = view
        view.onClick = { [weak self] in self?.perform { $0.clicked() } }
        view.onScroll = { [weak self] delta in self?.perform { $0.scroll(by: delta) } }
        NotificationCenter.default.addObserver(forName: NSApplication.didChangeScreenParametersNotification,
                                               object: nil, queue: .main) { [weak self] _ in
            self?.panel.anchor()
        }
    }

    // MARK: Inputs

    func receive(_ events: [PeekEvent]) {
        let focusedId = isClaudeFrontmost ? sessions.mostRecentlyFocusedId() : nil
        for event in events {
            if event.hostSessionId == focusedId {
                // Courtesy rule: Claude is in front showing this session already.
                NSLog("Peek: skipped event for the focused session %@", event.hostSessionId)
                continue
            }
            let title = SessionDirectory.displayTitle(info: sessions.info(for: event.hostSessionId), cwd: event.cwd)
            let message = Message(event: event, title: title)
            perform { $0.receive(message, now: Date()) }
        }
    }

    func greet() {
        perform { $0.greet() }
    }

    func perform(_ input: (inout Director) -> [Director.Effect]) {
        for effect in input(&director) {
            switch effect {
            case .animate(let animation): start(animation)
            case .open(let url): NSWorkspace.shared.open(url)
            case .chirp: if Settings.soundOn { Chirp.play() }
            case .restartBubbleTimer: bubbleRemaining = Timing.bubbleStays
            }
        }
        if director.phase != .hidden { startClock() }
    }

    private var isClaudeFrontmost: Bool {
        NSWorkspace.shared.frontmostApplication?.bundleIdentifier == Self.claudeBundleId
    }

    // MARK: Clock

    private var now: Double { ProcessInfo.processInfo.systemUptime }

    private func start(_ animation: Director.Animation) {
        motion = Motion(animation, from: pose)
        motionStart = now
        if !panel.isVisible {
            panel.anchor()
            panel.orderFrontRegardless()
        }
    }

    private func startClock() {
        guard clock == nil else { return }
        lastTick = now
        let timer = Timer(timeInterval: 1.0 / 60, repeats: true) { [weak self] _ in self?.tick() }
        RunLoop.main.add(timer, forMode: .common)
        clock = timer
    }

    private func tick() {
        let t = now
        let dt = t - lastTick
        lastTick = t

        if let m = motion {
            pose = m.pose(at: t - motionStart)
            if m.isFinished(at: t - motionStart) {
                motion = nil
                switch m.animation {
                case .enter, .enterPeeking: perform { $0.entranceFinished() }
                case .leave: perform { $0.leaveFinished() }
                case .hop, .duck, .unduck: break
                }
            }
        }

        // The bubble's countdown pauses while the pointer is over the pet or the bubble.
        let hovering = view.containsMouse
        if director.phase == .showing, motion == nil, !hovering {
            bubbleRemaining -= dt
            if bubbleRemaining <= 0 { perform { $0.bubbleTimedOut() } }
        }

        render(at: t)
        panel.ignoresMouseEvents = !hovering   // clicks anywhere else fall through to the app below

        if director.phase == .hidden {
            clock?.invalidate()
            clock = nil
            motion = nil
            pose = .offstage
            panel.orderOut(nil)
        }
    }

    private func render(at t: Double) {
        let bubble = director.bubbleMessage
        if bubble != shownMessage {
            shownMessage = bubble
            shownAt = t
        }
        let age = t - shownAt
        view.state = PetView.State(
            pose: pose,
            stride: pose.walking && Int(t / Timing.legFrame) % 2 == 1,
            blinking: t.truncatingRemainder(dividingBy: Timing.blinkEvery) < Timing.blinkFor,
            bubble: bubble,
            revealed: bubble.map { Int(Double($0.text.count) * min(1, age / Timing.typeOn)) } ?? 0,
            popScale: min(1, (age / Timing.bubblePop * 4).rounded(.up) / 4),
            bangOn: Int(t / Timing.bangBlink) % 2 == 0,
            badge: director.badgeCount
        )
    }
}

        menu.addItem(ClosureMenuItem("Dismiss all") { [weak self] in self?.perform { $0.dismissAll() } })

            menu.addItem(ClosureMenuItem("End quiet hour") { [weak self] in self?.endQuietHour() })
        } else {

        }
        menu.addItem(ClosureMenuItem("Sound", checked: Settings.soundOn) {
            Settings.soundOn.toggle()
            if Settings.soundOn { Chirp.play() }   // a preview, so you know what you turned on
        })
        menu.addItem(ClosureMenuItem("Open at login", checked: Settings.openAtLogin) {
            Settings.openAtLogin.toggle()
            LoginItem.apply()
        })
        menu.addItem(.separator())
        menu.addItem(ClosureMenuItem("Quit Peek") { NSApp.terminate(nil) })
        return menu
    }

    func startQuietHour() {

        Settings.quietUntil = until
        perform { $0.startQuiet(until: until) }
        scheduleQuietEnd()
    }

    func endQuietHour() {
        quietTimer?.invalidate()
        quietTimer = nil
        Settings.quietUntil = nil
        perform { $0.quietEnded() }
    }

    /// Arms a timer for the end of the quiet hour, including one that survived a relaunch.
    func scheduleQuietEnd() {
        quietTimer?.invalidate()
        quietTimer = nil
        guard let until = director.quietUntil else { return }
        let delay = until.timeIntervalSinceNow
        guard delay > 0 else {
            endQuietHour()
            return
        }
        quietTimer = Timer.scheduledTimer(withTimeInterval: delay, repeats: false) { [weak self] _ in
            self?.endQuietHour()
        }
    }

/// Open at login, through SMAppService (macOS 13+). Peek is ad-hoc signed; the status logged

#!/usr/bin/env python3
"""Add or remove Peek's entries in Claude Code's ~/.claude/settings.json.

install   registers Peek's hook for Stop and Notification (permission_prompt and
          elicitation_dialog), and turns off the everything-claude-code plugin's
          osascript banner (the one macOS shows as Script Editor) through its
          ECC_DISABLED_HOOKS switch. The plugin itself is not touched.
uninstall removes exactly those entries.

Before any change, a copy of the file is written next to it as
settings.json.peek-backup-<timestamp>. Run with python3 -I (standard library only).
"""
import argparse
import json
import os
import shutil
import time

HOOK = "$HOME/Applications/Peek.app/Contents/Resources/peek-hook"
# Guarded so that a missing Peek.app never shows up as a hook error in Claude.
COMMAND = f'h="{HOOK}"; [ -x "$h" ] && "$h"; exit 0'
MARKER = "Peek.app/Contents/Resources/peek-hook"
ECC_ID = "stop:desktop-notify"
EVENTS = {"Stop": None, "Notification": "permission_prompt|elicitation_dialog"}


def load(path):
    if not os.path.exists(path):
        return {}
    with open(path) as f:
        text = f.read()
    return json.loads(text) if text.strip() else {}


def save(path, data):
    if os.path.exists(path):
        shutil.copy2(path, f"{path}.peek-backup-{time.strftime('%Y%m%d-%H%M%S')}")
    os.makedirs(os.path.dirname(path) or ".", exist_ok=True)
    tmp = f"{path}.peek-tmp"
    with open(tmp, "w") as f:
        json.dump(data, f, indent=2)
        f.write("\n")
    os.replace(tmp, path)


def is_ours(group):
    return any(MARKER in h.get("command", "") for h in group.get("hooks", []))


def ecc_ids(env):
    return [i.strip() for i in env.get("ECC_DISABLED_HOOKS", "").split(",") if i.strip()]


def install(data):
    hooks = data.setdefault("hooks", {})
    for event, matcher in EVENTS.items():
        groups = hooks.setdefault(event, [])
        if not any(is_ours(g) for g in groups):
            group = {"hooks": [{"type": "command", "command": COMMAND, "timeout": 5}]}
            if matcher:
                group["matcher"] = matcher
            groups.append(group)
    env = data.setdefault("env", {})
    ids = ecc_ids(env)
    if ECC_ID not in ids:
        ids.append(ECC_ID)
    env["ECC_DISABLED_HOOKS"] = ",".join(ids)
    return data


def uninstall(data):
    hooks = data.get("hooks", {})
    for event in EVENTS:
        kept = [g for g in hooks.get(event, []) if not is_ours(g)]
        if kept:
            hooks[event] = kept
        else:
            hooks.pop(event, None)
    if "hooks" in data and not data["hooks"]:
        del data["hooks"]
    env = data.get("env", {})
    ids = [i for i in ecc_ids(env) if i != ECC_ID]
    if ids:
        env["ECC_DISABLED_HOOKS"] = ",".join(ids)
    else:
        env.pop("ECC_DISABLED_HOOKS", None)
    if "env" in data and not data["env"]:
        del data["env"]
    return data


def main():
    parser = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    parser.add_argument("action", choices=["install", "uninstall"])
    parser.add_argument("--settings", default=os.path.expanduser("~/.claude/settings.json"))
    args = parser.parse_args()
    before = load(args.settings)
    after = (install if args.action == "install" else uninstall)(json.loads(json.dumps(before)))
    if after == before:
        print(f"{args.action}: nothing to change in {args.settings}")
        return
    save(args.settings, after)
    print(f"{args.action}: updated {args.settings} (backup written next to it)")


if __name__ == "__main__":
    main()
```

# How Peek works, and the traps found building it

Peek replaces a notification banner that opened Script Editor. Everything below was found by
inspection on 2026-10-15 (Claude Desktop 2.37337.1, Claude Code 2.1.295). None of it is
documented by Anthropic, so it is the first thing to re-check after a Claude update.

## Why the old banner opened Script Editor

The banner came from the everything-claude-code plugin, not from Claude. Its `Stop` hook
(`stop:desktop-notify`, `scripts/hooks/desktop-notify.js`) runs
`osascript -e 'display notification ...'`. macOS attributes every notification posted by
`osascript` to Script Editor, so the banner shows Script Editor's icon and opens it on
click. There is no way to fix that from inside `osascript`. Peek turns that hook off with the
plugin's own switch, `ECC_DISABLED_HOOKS=stop:desktop-notify`, in `~/.claude/settings.json`
(`env`). The plugin is untouched and still updates normally.

## How Peek knows which session pinged

Every process a Claude Desktop Code session starts, hooks included, inherits
`CLAUDE_CODE_HOST_SESSION_ID=local_<uuid>`. That is the Desktop's id for the session, not the
CLI's `session_id` from the hook JSON. Terminal `claude` sessions do not have it, and
`hook/peek-hook` exits quietly without it.

## How a click opens the session

Claude Desktop's URL handler (in `/Applications/Claude.app/Contents/Resources/app.asar`)
accepts `claude://code/continue?session=local_<uuid>`. It opens that session if it exists
and isn't archived, and otherwise falls back to the Code home screen. Claude validates the id
with `^local_[A-Za-z0-9-]{1,64}$`; `DeepLink.swift` applies the same rule, so nothing from
the inbox can turn into an arbitrary URL.

To re-check after an update, search the bundle for the handler:

```bash
python3 -I -c "d=open('/Applications/Claude.app/Contents/Resources/app.asar','rb').read();i=d.find(b'code_continue');print(d[i-400:i+400].decode('utf8','replace'))"
```

## Where titles come from

`~/Library/Application Support/Claude/claude-code-sessions/<account>/<org>/local_<uuid>.json`
holds `title`, `isArchived`, `lastFocusedAt` and more. There were 180 files totaling 24 MB on
the dev Mac, so the courtesy rule reads only the 5 most recently modified. If the layout
changes, titles fall back to the project folder's name. Nothing breaks.

## The hook-to-app hand-off

`hook/peek-hook` writes `<epoch-ms>-<pid>.event` into
`~/Library/Application Support/Peek/inbox` (mode 700) through a temp file and a rename, so
Peek never reads half a file. Line 1 is the Desktop session id; the rest is the hook JSON,
capped at 1 MB. The remainder of stdin is drained so Claude never writes into a closed
pipe. Every path exits 0: a notification helper must never fail a Claude turn.

The inbox path is written in two places, `hook/peek-hook` and `Inbox.relativePath`.
`InboxTests.hookAndAppAgreeOnTheInboxPath` fails the build if they drift.

## Silent failures to know about

- If Peek isn't running, events wait in the inbox. Anything over an hour old is dropped
  unread at the next launch, on purpose.
- If `~/Applications/Peek.app` is deleted but the hooks are still registered, the guarded
  hook command exits 0 silently. Run `python3 scripts/hooks.py uninstall` to remove the entries.
- Settings and env load when a Claude session starts. Sessions that were already open when
  you installed the hooks won't ping Peek until they're restarted.
- Open at login uses `SMAppService` with an ad-hoc signature. `log show --last 5m
  --predicate 'process == "Peek"' | grep "login item"` shows its status (1 = enabled).

# Peek

A small pixel pet that pops out of the bottom-right corner of your screen when a Claude
Desktop Code session finishes or needs you. Click its speech bubble to jump straight to that
session.

- Messages queue oldest first, one per session. Scroll over the bubble to flip through them.

  unread messages. Click the peek to bring them back.
- Right-click for Dismiss, Dismiss all, Quiet for 1 hour, Sound, Open at login, and Quit Peek.
- Open Peek from Finder or Spotlight while it's running to call the pet out.

Sessions already open keep their old settings until restarted.
